# Sample data (FAKE)

These files are **not NIST data**. They are invented numbers made by
`scripts/make_sample_data.py` (rules in `src/synthetic.py`).

They have the same layout as the registered NIST "Overhang Part X4" files
(one folder per part, one CSV file per layer, 40 columns), so the tests and
the quick start can run without the big download.

Results on this data only show that the code works.
